TOOL INSTRUCTIONS

Upload Master Locations: Click the Upload Location File button in the top header and select your formatted Excel or CSV file.

Configure Working Days: Under the Daily Count Sheet tab, input your annual Working Days in Year (default is 250). The tool will automatically compute a suggested daily target, which you can manually edit if desired.

Generate Daily Sheet: Click Generate & Log Daily Count Sheet to randomize and assign today's quota of uncounted locations.

Record Notes & Export: Enter any variance remarks directly into the table rows. Use the Export CSV or Export Excel buttons to download today's sheet for floor workers.

Track Progress: Switch to the Master Tracking Dashboard tab to monitor overall cycle completion metrics, review historical counts, and export master status reports.

DATA IMPORT SPECIFICATIONS 

Check File Formats: Accepted file extensions are .xlsx, .xls, or .csv. 

Data Structure: The tool reads to the worksheet and processes the first column of the file. 

Value Formatting: Each row in the primary column represents a warehouse location identifier (Location ID). Values are automatically trimmed and standardized to a maximum length of 4 alphanumeric characters.

Duplicates: Duplicate location identifiers are automatically consolidated into unique master records upon import.
